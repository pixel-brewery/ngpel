# @pixel-brewery/ngpel-ui

## 0.1.0 (2026-11-12)

- Removes the ApexCharts integration and the exported `ChartTheme`, `ChartLayout` and `IChartOptions` helpers.
- Updates `tslib` to 2.9.1 and aligns the ngpel peer versions to 0.1.0.

## 0.0.3 (2026-11-06)

- Adds context menus, table preferences and loading states, collapsible navigation, and shared session controls.
- Adds a dedicated context overlay entry point for Mosaik drawers.
- Requires Mosaik 0.1.188 or newer for the Mosaik integration.

## 0.0.2

- First public distribution of the UI library, including the Markdown and widget entry points.
