# Changelog

## 0.1.0 (2026-11-12)

- Updates the Angular, Nx and Mosaik toolchain and verifies all five packed libraries in an Angular consumer.
- Resolves duplicate CodeMirror dependencies and updates the UI tests for jsdom 31.
- Removes `ChartTheme`, `ChartLayout` and `IChartOptions` from `@pixel-brewery/ngpel-ui`.

## 0.0.3 (2026-11-06)

- Adds shared search, browser, routing, and UI capabilities for Angular applications.
- Updates the optional Mosaik integration to Mosaik 0.1.188 and verifies the five packages together.

## 0.0.2

- First coordinated release from the public ngpel repository: core, mvp, forms, router and ui.
- Adds the presenter behaviors and compatibility contracts described in the
  [migration guide](.docs/guides/patterns-and-practices.md).
